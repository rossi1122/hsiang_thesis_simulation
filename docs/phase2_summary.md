# Phase 2 總結：Yang 2024 在 X-Plane 11 的重現（2026-11-18）

> 細節、每次實驗的數據與和論文不同的地方，都在 `docs/reproduction_log.md`。這份是給下次報告用的重點整理。

## 1. 做了什麼

| 項目 | 內容 |
|---|---|
| 平台 | X-Plane 11 雙機：飛機 PC（SP80）＋筆電（吉普車），XPlaneConnect＋Python；YOLO（yolo_jeep12）截螢幕偵測 |
| 尺度 | SP80 實測在 18.6 m/s、坡度 20° 就失速，飛不了論文的 16 m/s → 依無因次量放大：V = 30 m/s、H = 300 m（長度 ×3、時間 ×1.6）。R_d = 150 m、R_M = 300 m、u_max = 0.3125 rad/s、Δt = 0.08 s；目標 V_c = 7 / 9 / 10 → 吉普車 13.1 / 16.9 / 18.75 m/s |
| u_ψ → 舵面 | 論文沒寫 → 傾斜轉彎內迴路：φ_cmd = −atan(V·u_ψ/g) → 副翼；方向舵協調轉彎；高度 → 俯仰 → 升降舵；空速 → 油門 |
| 飛機動態辨識 | 階躍測試三次一致：實際航向率跟上 u_ψ 的一階時間常數 **τ ≈ 0.52 s**、延遲約 0.05 s；u_max 時實際轉彎率是命令的約 1.05 倍 |
| 相機校正 | f = 1662.8 px、主點 (960, 510)、俯仰校正 7°；YOLO 與真值投影差 3–5 px |

## 2. 重現結果：和論文的趨勢一致

| 實驗 | X-Plane RMSE（換算 f = 537） | 論文 RMSE | 超出 R_M | 結論 |
|---|---|---|---|---|
| A 切換式 V_c = 7 | 124.1 | 153.63 | 0 s | 提出方法比 LSM 好 26%（論文 32%） |
| B LSM V_c = 7 | 167.7 | 226.55 | 67 s（每圈一次） | 只有 LSM 會超出 R_M |
| C 切換式 V_c = 9 | 189.1 | 238.38 | 3.8 s（只有開頭） | P₁,soft 的 RMSE 較低，和論文一致 |
| D P₁,soft V_c = 9 | 169.6 | 228.56 | 3.9 s（只有開頭） | 穩態兩者幾乎相同（161 vs 164） |

- X-Plane 比數值模擬「好一點」的原因已驗證：SP80 打滿時多轉約 5%。數值模擬加入 τ = 0.52 s 與 5% 增益後，超出 R_M 的時間與 X-Plane 幾乎相同（B：68.2 vs 67.1 s；C：3.7 vs 3.8 s；D：4.2 vs 3.9 s）。
- **YOLO 取代真值**（實驗 A）：偵測率 98–99.7%、延遲約 45 ms、誤差 7–8 px；穩態 RMSE 只差 0.5–3%。偵測「誤差」不是問題，「偵測不到」才是問題。

## 3. 老師疑慮 (1)：目標在遠處時演算法怎麼運作

從吉普車正後方 900 m（論文尺度 300 m）起始、V_c = 10：

| | 切換式（E1） | P₁,soft（E2，不切換） | 數值預測 |
|---|---|---|---|
| 追近時的飛法 | J_g：直飛目標（目標在機頭右前 8°） | J₁：先轉彎把目標擺到右前 45°，斜著接近 | — |
| 進入 R_M | **51.5 s** | 81.3 s | 54.1 / 80.5 s |
| 進入後超出 R_M | **12%**（每次 1–12 s） | 35%（每次 15–27 s） | 13% / 31% |
| 進入後 RMSE | 286.8 | 216.8 | — |

- **答案**：遠處時 Yang 的方法靠切換機制的 J_g「朝目標直飛」把距離拉回；盤旋的目標函數 J₁ 只在近距離有意義。論文所有實驗都從 85 m 起始，看不到這一段。
- 切換的貢獻是「**不跟丟**」，不是「追得更準」：P₁,soft 進入後的 RMSE 反而較低，但超出 R_M 的時間是 3 倍。

## 4. 老師疑慮 (2)：方程式和 MPC 的關係

| 論文方程式 | 在 MPC 裡的角色 |
|---|---|
| Eq. 7（Ideal State） | 把量測轉成 MPC 的**狀態** s₂ |
| **Eq. 8、10** | **預測模型**：u_ψ 會讓 s₂ 怎麼變，預測 15 步（1.2 s） |
| Eq. 12–14 | **硬約束**：\|u_ψ\| ≤ u_max、\|Δu_ψ\| ≤ a_max |
| Eq. 15、20、27 | **軟約束**：預測會跑出感知範圍就重罰 |
| Eq. 24、35、37 | 收縮約束：下一步誤差要比現在小 |
| Eq. 30、36、38 | **成本函數** J₁（盤旋）、J_g（拉回）、J₂（過渡） |
| Eq. 40–43 | 切換：計數器 n₁ 決定用哪個成本函數 |
| Eq. 31–32 | 初始猜測（warm start） |

每 0.08 s：用 Eq. 8 預測 15 組未來命令的後果 → 依成本函數挑最好的 → 只送出第一個 u_ψ → 下一步重來。三種模式輸出的都只有 u_ψ。

## 5. 改良版環境（增穩雲台＋跟丟處理）

**起因**：YOLO 版 E1 在 129.6 s 跟丟後完全失控（R 拉到 1187 m）。切換時坡度突然反向（往左傾 46°、目標在右下方），原版兩軸機身雲台的 tilt 撞到 −89° → 目標出畫面；程式沿用舊像素，雲台以 172°/s 一直轉圈。

**改良**（Yang 的 MPC、切換、Eq. 8 都不改；`--yang-original` 可回到原版）：
1. **SIYI A8 mini 跟隨模式**的三軸增穩雲台（官方規格：yaw ±160°、pitch −135°～+45°、roll ±30°）。
2. **跟丟處理**：偵測不到時用 Eq. 10＋實測航向變化率推算 s₂，雲台對準推算方向（不做定位）。

| | YOLO 原版 | YOLO 改良版 |
|---|---|---|
| camera_check（坡度 +30° / −46°） | — | 誤差 ≤ 3.4 px |
| E1（前 150 s）超出 R_M | 26%，跟丟後飛到 826 m | **12%**，最遠 328 m（truth 原版 7%） |
| E1 偵測率 / 最長跟丟 | 72% / 到結束都沒找回 | **97.4% / 0.38 s** |
| A（前 150 s）RMSE | 137.6 | 139.4（truth 原版 130.6） |
| A 偵測率 / 最長跟丟 | 98.2% / — | **99.7% / 0.15 s** |

→ 改良版解決了感知與雲台的問題，**沒有改變 Yang 方法本身的表現**；剩下的誤差來自控制器的預測模型。之後 C1–C3 都在改良版環境比較。

## 6. 對論文方向的證據（RQ1：哪些沒建模的運動在影響追蹤）

| 來源 | 證據 |
|---|---|
| **④ 目標運動** | V_c = 9、10 時盤旋退化成「繞一圈 → 落後 → 追趕」：C 的 R 停在 284–291 m 的平台、E1 每約 60 s 超出 R_M 一次；s₂ 從來不會收斂到 0。Eq. 8 把目標當成靜止的 |
| **② 飛機動態** | 論文自己的起始條件就貼著 R_M（理想 0.96 R_M，加入 τ = 0.52 s 後 0.998 R_M），實際飛行時常擦到邊界而切換；SP80 轉彎率只要比模型多 5%，P₁,soft 超出 R_M 的時間就從 28 s 降到 4 s，「切換 vs 不切換」的結論跟著改變 |
| **③ 雲台** | 雲台由 Eq. 9 獨立計算、不在 MPC 裡；坡度突然反向時兩軸雲台撞到極限、目標出畫面而跟丟 |
