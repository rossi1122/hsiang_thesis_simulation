## 2. 情境假設（已確定）

- 飛機**定高、定空速**（由自駕儀 TECS 維持），MPC 只輸出偏航率 u_ψ。
  - 定空速 ≠ 定地速：有風時地速隨航向變化，影響 IBVS 模型中的 V_t。
- 目標約 15 m/s 等速直線；飛機從後方追擊，追上後盤旋。
  - 飛機比目標快時無法一直留在後方，必然要盤旋或蛇行，這正是「追擊 → 盤旋」兩階段的來源。
- 偵測在機上 Orin NX 執行（不是透過 UART 從別台電腦接收）。

### 2.1 論文方向：運動感知 IBVS-MPC（2026-11-15 整理）

**暫定題目**：考慮載具與目標運動之固定翼雲台影像式模型預測追蹤控制
（Motion-Aware Image-Based MPC for Fixed-Wing UAV Ground Target Tracking with a Gimbal Camera）

**問題定義**：畫面上目標的移動 = ① 飛機平移與偏航 + ② 飛機姿態（滾轉、俯仰）+ ③ 雲台轉動 + ④ 目標自己移動。
- Yang 2024 只考慮 ①（且假設 u_ψ 立即生效）；② 只在量測端用 Ideal State 換算、預測中沒有；③ 雲台由 Eq. 9 獨立計算、不在 MPC 內；④ 完全沒有。
- 報告用語：「Yang 2024 只考慮飛機的**理想運動學**，沒有考慮飛機的**姿態動態**、**雲台運動**與**目標運動**對影像的影響。」（比「完全沒考慮飛機運動」更精確。）

**研究問題**
- RQ1：Yang 2024 中有多少影像誤差來自沒有建模的運動？各來源影響多大？
- RQ2：能否只用影像與已知的飛機、雲台狀態估出目標造成的影像運動，且不做目標定位？
- RQ3：把這些運動放進 MPC 預測後，追蹤是否更穩定、更準確（尤其目標快、遠距離起始、目標轉彎）？

**貢獻**
- C1 運動感知影像預測模型：Eq. 8 + 滾轉動態 + 雲台運動 + 目標運動。
- C2 影像平面目標運動估測：∂s/∂t ≈ ṡ(量測) − 已知自身運動；KF（等速／IMM）+ DKF。
- C3 運動感知切換式 MPC：Yang 的切換與感知範圍約束 + C1 模型（必要時雲台一起最佳化）。

**在 MPC 中「額外修正命令」的意義**：目標運動放進預測模型後，MPC 會自動算出帶有提前量的 u_ψ，不需要像 PNG 那樣另外加一項。

**與 Li 2026 的根本差別**：Li 把所有誤差打包成一項 d 修正畫面；本論文**依來源分開建模**，已知的直接算、未知的（目標）才估，每一項都有物理意義、可以各自驗證，而且在 X-Plane 中（吉普車真的在動、飛機真的有滾轉延遲）就能看到效果。

**風險**：飛機／雲台狀態與影像時間不同步（會被誤認成目標運動）；L·v_c 需要深度（用 H/sin(tilt) 當增益，不定位）；目標轉彎時等速模型不足（改 IMM）；模型變複雜導致求解變慢（先加 ④，再視求解時間加 ②③）。

## 3. 對 Yang 2024 的理解重點

### 3.1 偏航率與飛機命令
- u_ψ = ψ̇，**航向變化率**（不是機體偏航角速度 r；協調轉彎時 r = ψ̇·cosφ）。
- 固定翼靠滾轉轉彎：`φ = atan(V·ψ̇ / g)`，`R = V/ψ̇`，`n = 1/cosφ`。
  - Yang 參數 V=16 m/s、u_max=0.5 rad/s → φ ≈ 39°、R ≈ 32 m、n ≈ 1.29。
- 論文的 HITL 是 Xavier NX + ROS → MAVROS → PX4 → Gazebo，**沒有寫 u_ψ 怎麼轉成 PX4 命令**。本專案採 `φ_cmd = atan(V·u_ψ/g)`，pitch/油門由自駕儀維持定高定速，方向舵只做協調。
- 三種切換模式（J_g / J₂ / J₁）**輸出的都只有 u_ψ**，差別只在成本函數與約束；雲台由 Eq. 9 獨立計算。

### 3.2 深度 z_c
- 在 Eq. 8 中只出現在 `(f/z_c)·V_t`：前進造成畫面橫向漂移的換算增益。u_ψ 那一欄沒有 z_c，所以估錯只造成偏差、不改變迴路增益。
- 取得方式：`z_c ≈ H / sin(tilt)`（平地假設）。不建議用 bbox 像素大小推深度（20–40 px 時雜訊 ±5–15%、需已知車輛尺寸、接近單目測距）；像素大小可用來離線決定 L_M（最遠可靠偵測距離）。
- 用 z_c 當增益仍是 IBVS，不是 PBVS。

### 3.3 Ideal State 與盤旋
- 虛擬相機朝側面（θ_p = −π/2）、俯視 α；s₂ = 0 等價於以 R_d 盤旋。
- 驗證：u₂ = v₂ = 0 時 u̇₂ = 0 ⇒ |u_ψ| = V_t/(z_c cosα) = V_t/R_d。
- 若要做「從後方追擊」，需另定義朝前的虛擬相機（θ_p = 0），目標在正前方；速度相同才能穩定維持在後方。

### 3.4 結果的解讀
- 切換機制的貢獻是「**不跟丟**」（R < R_M），不是「追得更準」（V_c = 9 m/s 時 RMSE 反而 +4.3%）。
- 只驗證到 V_c/V_t ≤ 0.56；HITL 的改善幅度縮小（−12%、−5%）。
- RMSE 本身很大（150–270 px，f = 537），s₂ 長時間沒有收斂：預測模型沒有目標運動項。
- HITL 中 u_ψ 經常飽和在 ±0.5 rad/s（即使 V_c = 5 m/s）；(u₁, v₁) 有姿態與雲台延遲造成的抖動。

### 3.5 已知疑點
- Eq. 40 的 n₁ 對應與文字相反（以文字為準）。
- u_ψ → 自駕儀命令的轉換未說明。

## 5. 已排除或暫緩的方向

- 單目目標定位（老師排除）。
- 以改善盤旋軌跡為貢獻，例如 MPCC（老師認為是情境假設）。
- IBVS + PID 作為主控制器（老師認為不足以構成論文）。
- Li 2026 ESKF-PRE 作為改進方法（2026-11-13 正式排除：畫面修正、與目標無關、固定式相機、模擬看不出效果）。
- 直接套用 Yan 2025 的 PNG 攔截導引律（任務是攔截，不是追蹤；只借影像式 LOS 估測）。
- 全套 MOT（ByteTrack/BoT-SORT）：單目標用不到 ID 管理，20–40 px 時 ReID 無效。

### 2.2 2026-11-19 之後的情境（取代第 2 節的盤旋為主）
- 長程追蹤：起點 ≥ 900 m，主要追蹤距離 400–700 m（YOLO 偵測率 ≥ 92%、雲台轉速 < 1 °/s）。
- 目標 20、25 m/s（V_c/V_t = 0.67、0.83），會**右轉 90°**：老師的意思是真實車輛轉彎會自然掉速（側向加速度有上限），
  不是任意設定先減速；大半徑曲線才不掉速。之後再做曲線。
- 模式：追近 → 跟隨（目標快）→ 盤旋（目標慢，例如轉彎時）。
- 雲台：真實轉速與角度限制（待實機量測 SIYI A8 mini）；雲台與飛機整合（MPC 約束＋前饋）。
- 詳細計畫：`docs/plan_20261121.md`。
