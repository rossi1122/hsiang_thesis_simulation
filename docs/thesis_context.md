## 2. 情境假設（已確定）

- 飛機**定高、定空速**（由自駕儀 TECS 維持），MPC 只輸出偏航率 u_ψ。
  - 定空速 ≠ 定地速：有風時地速隨航向變化，影響 IBVS 模型中的 V_t。
- 目標約 15 m/s 等速直線；飛機從後方追擊，追上後盤旋。
  - 飛機比目標快時無法一直留在後方，必然要盤旋或蛇行，這正是「追擊 → 盤旋」兩階段的來源。
- 偵測在機上 Orin NX 執行（不是透過 UART 從別台電腦接收）。

## 3. 對 Yang 2024 的理解重點

### 3.1 偏航率與飛機命令
- u_ψ = ψ̇，**航向變化率**（不是機體偏航角速度 r；協調轉彎時 r = ψ̇·cosφ）。
- 固定翼靠滾轉轉彎：`φ = atan(V·ψ̇ / g)`，`R = V/ψ̇`，`n = 1/cosφ`。
  - Yang 參數 V=16 m/s、u_max=0.5 rad/s → φ ≈ 39°、R ≈ 32 m、n ≈ 1.29。
- 論文的 HITL 是 Xavier NX + ROS → MAVROS → PX4 → Gazebo，**沒有寫 u_ψ 怎麼轉成 PX4 命令**。本專案採 `φ_cmd = atan(V·u_ψ/g)`，pitch/油門由自駕儀維持定高定速，方向舵只做協調。
- 三種切換模式（J_g / J₂ / J₁）**輸出的都只有 u_ψ**，差別只在成本函數與約束；雲台由 Eq. 9 獨立計算。

### 3.2 深度 z_c
- 在 Eq. 8 中只出現在 `(f/z_c)·V_t`：前進造成畫面橫向漂移的換算增益。u_ψ 那一欄沒有 z_c，所以估錯只造成偏差、不改變迴路增益。
- 取得方式：`z_c ≈ H / sin(tilt)`（平地假設）。不建議用 bbox 像素大小推深度（20–40 px 時雜訊 ±5–15%、需已知車輛尺寸、接近單目測距）；像素大小可用來離線決定 L_M（最遠可靠偵測距離）。
- 用 z_c 當增益仍是 IBVS，不是 PBVS。

### 3.3 Ideal State 與盤旋
- 虛擬相機朝側面（θ_p = −π/2）、俯視 α；s₂ = 0 等價於以 R_d 盤旋。
- 驗證：u₂ = v₂ = 0 時 u̇₂ = 0 ⇒ |u_ψ| = V_t/(z_c cosα) = V_t/R_d。
- 若要做「從後方追擊」，需另定義朝前的虛擬相機（θ_p = 0），目標在正前方；速度相同才能穩定維持在後方。

### 3.4 結果的解讀
- 切換機制的貢獻是「**不跟丟**」（R < R_M），不是「追得更準」（V_c = 9 m/s 時 RMSE 反而 +4.3%）。
- 只驗證到 V_c/V_t ≤ 0.56；HITL 的改善幅度縮小（−12%、−5%）。
- RMSE 本身很大（150–270 px，f = 537），s₂ 長時間沒有收斂：預測模型沒有目標運動項。
- HITL 中 u_ψ 經常飽和在 ±0.5 rad/s（即使 V_c = 5 m/s）；(u₁, v₁) 有姿態與雲台延遲造成的抖動。

### 3.5 已知疑點
- Eq. 40 的 n₁ 對應與文字相反（以文字為準）。
- u_ψ → 自駕儀命令的轉換未說明。
